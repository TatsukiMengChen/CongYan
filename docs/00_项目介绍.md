# 00. 项目介绍

## 1. 项目概述

**聪言 (CongYan)** 是一款专为发音障碍用户（如脑瘫患者、声带受损者、听力障碍康复者等）设计的医学AI辅助应用。项目旨在通过前沿的智能技术，为用户提供普通话发音的精准检测与评分，并结合历史记录进行发音口型、发音结构的深度分析，最终生成个性化的康复训练指导。

本项目是一个科研性质的应用，其核心目标是帮助用户改善发音能力、提升交流效率，并为言语康复训练提供科学、智能的辅助手段。

- **项目版本**: `1.0.3`
- **应用标识**: `com.congyan.app`

## 2. 功能特点

- **普通话检测评分**：实现对用户普通话发音的实时检测和专业评分。
- **深度发音分析**：能够检测具体汉字的声母、韵母发音，并提供详尽的分析报告。
- **历史记录与追踪**：根据用户的历史训练记录，长期分析其发音习惯和进步情况。
- **个性化发音训练**：基于用户的发音评估结果，智能生成高度定制化的发音训练计划。
- **语音合成 (TTS)**：内置强大的文字转语音功能，为发音障碍用户在日常交流中提供便利。
- **医学康复指导**：结合医学知识库，为用户提供发音障碍的初步诊断建议，并推荐相应的康复方向。

## 3. 技术架构

聪言采用现代化的跨平台应用架构，确保在不同设备上都能提供一致且流畅的用户体验。

### 3.1. 整体架构

项目采用前后端分离的模式：

- **前端**: 使用 [Tauri](https://tauri.app/) 框架构建的跨平台桌面应用，负责用户界面和交互。
- **后端**: 独立的后端服务，负责处理核心业务逻辑、数据存储和AI模型计算。后端项目地址位于：[congyan_backend](https://github.com/jcmz19/congyan_backend/)。

### 3.2. 前端技术栈

- **应用框架**: [Tauri](https://tauri.app/) (使用 Rust)
- **UI 框架**: [React](https://react.dev/) (v18)
- **编程语言**: [TypeScript](https://www.typescriptlang.org/)
- **状态管理**: [Zustand](https://github.com/pmndrs/zustand)
- **UI 组件库**: [Ant Design](https://ant.design/) & [MUI](https://mui.com/)
- **原子化 CSS**: [UnoCSS](https://unocss.dev/)
- **HTTP 请求**: [Axios](https://axios-http.com/)
