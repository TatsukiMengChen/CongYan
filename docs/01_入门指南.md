# 01. 入门指南

本指南将帮助开发者快速搭建聪言应用的本地开发环境。

## 1. 环境要求 (Prerequisites)

在开始之前，请确保你的开发环境中已安装以下软件和工具。

- **Node.js**: `v18.0` 或更高版本。
- **pnpm**: 本项目使用的包管理器。如果尚未安装，可以通过 `npm install -g pnpm` 进行全局安装。
- **Rust**: [Rust 编程语言环境](https://www.rust-lang.org/tools/install)。Tauri 的后端是基于 Rust 构建的。
- **Tauri 环境依赖**: 需要为特定操作系统安装相应的编译工具链和 WebView2 (Windows) / WebKit (macOS) 等。请务必遵循 [Tauri官方文档](https://tauri.app/v1/guides/getting-started/prerequisites) 完成环境配置。
- **Git**: 用于克隆项目代码仓库。

### 推荐的 IDE

- [Visual Studio Code](https://code.visualstudio.com/)
- **推荐插件**:
  - [Tauri](https://marketplace.visualstudio.com/items?itemName=tauri-apps.tauri-vscode)
  - [rust-analyzer](https://marketplace.visualstudio.com/items?itemName=rust-lang.rust-analyzer)
  - [UnoCSS](https://marketplace.visualstudio.com/items?itemName=unocss.unocss)

## 2. 安装与启动

### 2.1. 克隆项目

```bash
git clone <repository-url>
cd congyan
```

### 2.2. 安装依赖

本项目使用 `pnpm` 进行依赖管理。在项目根目录下，执行以下命令安装前端和后端依赖：

```bash
pnpm install
```

`pnpm install` 会同时安装 Node.js 模块和 Rust Crate。

### 2.3. 运行开发环境

安装完所有依赖后，执行以下命令即可启动应用的开发模式：

```bash
pnpm dev
```

此命令会同时启动 Vite 前端开发服务器和 Tauri 后端进程。应用将以开发模式启动，并开启热重载功能。对前端代码的任何修改都会实时反映在应用窗口中。

### 2.4. 环境变量

应用可能依赖一些后端服务的地址作为环境变量。请在项目根目录创建一个 `.env.local` 文件，并根据需要配置以下变量：

```env
# 示例: 后端 API 服务地址
VITE_API_BASE_URL=http://localhost:8000/api
```

_(具体的环境变量请参考团队规范或询问项目负责人)_

## 3. 常用脚本

在 `package.json` 中定义了一些常用脚本：

- `pnpm dev`: 启动开发模式。
- `pnpm build`: 对前端代码进行生产环境构建，并将产物输出到 `dist` 目录。
- `pnpm tauri build`: 构建并打包生产环境的Tauri应用（例如 .exe, .dmg, .deb）。
- `pnpm tauri info`: 查看Tauri环境相关信息，用于调试环境问题。
