# 医生端患者档案与语料辅助生成功能计划与ToDoList

## 一、背景与目标

为医生端提供患者档案留档、康复进度填写、OCR辅助填充、训练语料智能生成等功能，提升医生工作效率和档案规范性。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位医生端档案相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、API调用方式。
3. `src/pages/` 下医生端档案页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展OCR、语料生成API调用。
5. 后端API文档，明确通用OCR、语料生成API参数与返回值。

## 三、详细实现计划

### 1. 需求分析

- 支持患者基础信息建档、康复进度结构化填写、OCR辅助填充、个性化训练语料生成。

### 2. 技术方案

- 前端：档案信息卡片、标签栏、检索筛选、进度表、表单、OCR上传、语料生成面板等组件。
- 后端：OCR识别、语料生成、数据存储。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端API路径、参数、返回值。

#### 3.2 前端开发

- 患者档案区：实现信息卡片、标签栏、检索筛选模块，支持手动编辑/扫码导入、标签勾选、快捷搜索。
- 康复进度区：实现时间轴进度表、评估表单、主观评价、OCR上传与识别、字段高亮与一键填充。
- 语料生成区：实现语料生成控制面板、难度调节、方言适配、语料预览与编辑、同步导出。

#### 3.3 后端对接

- 确认OCR、语料生成API可用。
- 支持多类型数据输入，处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同档案、图片、语料内容下的功能效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如进度提示、字段高亮、导出格式等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
