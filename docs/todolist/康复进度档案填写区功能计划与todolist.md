# 康复进度档案填写区功能计划与ToDoList

## 一、背景与目标

为医生端提供康复进度档案填写区，结构化记录患者训练数据与评估结果，支持时间轴、评估表单、主观评价、OCR智能填充等功能。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位康复进度相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、API调用方式。
3. `src/pages/` 下康复进度页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展档案填写、OCR API调用。

## 三、详细实现计划

### 1. 需求分析

- 支持时间轴式进度表、评估指标表单、主观评价、OCR智能填充，自动关联历史训练数据。

### 2. 技术方案

- 前端：时间轴、表单、语音转文字、OCR上传与识别等组件。
- 后端：档案数据存储、OCR识别API。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端API路径、参数、返回值。

#### 3.2 前端开发

- 实现时间轴式进度表，支持按日期切换填写档案。
- 实现评估指标表单，支持声母/韵母正确率、发音时长、音调稳定性等指标填写。
- 实现主观评价区，支持医生备注、配合度评分、语音转文字。
- 实现OCR上传入口，支持拍照/上传病历文档，自动识别并高亮可填充字段，一键同步。

#### 3.3 后端对接

- 确认档案填写、OCR识别API可用。
- 支持多类型数据输入，处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同档案、图片、指标内容下的功能效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如进度提示、字段高亮等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
