# 方言发音问答与音频生成功能计划与ToDoList

## 一、背景与目标

为普通话不标准及不识字、受教育程度低的人群提供方言发音问答和音频生成服务。用户可用方言自由提问，系统基于大模型理解并生成方言文本及音频输出，提升沟通效率和可达性。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位问答与音频相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、API调用方式。
3. `src/pages/` 下相关页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展方言问答与音频生成API调用。
5. 后端API文档，明确方言自由说API、音频生成API参数与返回值。

## 三、详细实现计划

### 1. 需求分析

- 用户可选择方言，自由输入或语音输入问题，系统用大模型理解并用方言生成答案及音频。

### 2. 技术方案

- 前端：方言选择、文本/语音输入、API调用、结果展示与音频播放。
- 后端：大模型问答、方言文本生成、音频合成。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端API路径、参数、返回值。

#### 3.2 前端开发

- 新增“方言问答”入口，支持方言选择。
- 支持文本输入和语音输入（调用语音识别API）。
- 提交问题后，调用后端大模型问答API，传递方言类型和问题内容。
- 展示大模型返回的方言答案文本。
- 调用音频生成API，将答案文本转为音频，支持播放和下载。

#### 3.3 后端对接

- 确认大模型问答API、音频生成API可用。
- 支持多方言参数，处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同方言、输入方式下的问答与音频效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如进度提示、音频加载优化等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
