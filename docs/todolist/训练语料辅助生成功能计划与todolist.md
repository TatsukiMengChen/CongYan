# 训练语料辅助生成功能计划与ToDoList

## 一、背景与目标

为医生端和患者端提供智能训练语料生成区，基于患者障碍类型、训练难度、方言适配等参数，自动生成个性化训练语料，支持编辑、同步、导出。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位语料生成相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、API调用方式。
3. `src/pages/` 下语料生成页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展语料生成API调用。
5. 后端API文档，明确语料生成API参数与返回值。

## 三、详细实现计划

### 1. 需求分析

- 支持障碍类型选择、难度调节、方言适配、语料预览与编辑、同步导出等功能。

### 2. 技术方案

- 前端：语料生成控制面板、难度滑块、方言开关、预览编辑区、导出工具。
- 后端：语料生成API、数据存储。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端API路径、参数、返回值。

#### 3.2 前端开发

- 实现语料生成控制面板，支持障碍类型、难度、方言等参数选择。
- 实现语料预览与编辑区，支持增删改、发音重点标注。
- 实现一键同步、导出为PDF/音频等功能。

#### 3.3 后端对接

- 确认语料生成API可用。
- 支持多参数输入，处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同参数、语料内容下的生成效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如导出格式、编辑工具等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
