# 医生端智能决策功能计划与ToDoList

## 一、背景与目标

为医生端提供智能决策支持，基于患者历史训练数据、个人信息及相似病例，推荐成功康复方案，辅助医生科学决策。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位医生端相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、API调用方式。
3. `src/pages/` 下医生端页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展蓝心70B、文本向量、相似度API调用。
5. 后端API文档，明确各API参数与返回值。

## 三、详细实现计划

### 1. 需求分析

- 医生可查看患者历史数据，系统自动推荐相似病例及康复方案。

### 2. 技术方案

- 前端：患者数据展示、推荐结果展示、交互操作。
- 后端：大模型推理、相似度计算、康复方案检索。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端API路径、参数、返回值。

#### 3.2 前端开发

- 医生端页面集成“智能决策”入口。
- 展示患者历史数据、个人信息。
- 调用后端API获取相似病例及康复方案推荐。
- 支持医生查看、筛选、采纳推荐方案。

#### 3.3 后端对接

- 确认蓝心70B、文本向量、相似度API可用。
- 支持多维度数据输入，处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同患者数据下的推荐效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如进度提示、推荐理由展示等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
