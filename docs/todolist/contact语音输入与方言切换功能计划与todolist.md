# contact页面语音输入与方言切换功能实现计划与ToDoList

## 一、背景与目标

为contact页面新增语音输入功能，用户可通过语音录入联系方式内容，并支持切换为指定方言（如普通话、粤语、四川话等）进行语音识别，提升输入效率和多样性。

## 二、文档与代码调研

### 需阅读文档/代码：

1. `docs/02_项目结构.md`：了解contact页面及相关模块结构。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：前端页面结构、API调用方式。
3. `docs/modules/02_contact.md`：联系页面功能说明。
4. `src/pages/contact/` 下页面代码，定位集成入口。
5. `src/api/` 目录下API相关文件，查找/扩展语音识别接口调用。
6. 后端语音识别接口文档或代码，明确接口参数（如音频、方言类型）与返回值。

## 三、详细实现计划

### 1. 需求分析

- contact页面新增语音输入，支持多种方言切换，提升输入效率和适用性。

### 2. 技术方案

- 前端：录音、方言切换、接口调用、结果展示与编辑。
- 后端：语音识别，支持多方言参数，返回文本。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端语音识别接口路径、参数（音频、方言类型）、返回值。

#### 3.2 前端开发

- contact页面新增“语音输入”按钮。
- 弹出录音控件，支持开始/结束录音。
- 提供方言选择（下拉框或按钮组），如普通话、粤语、四川话等。
- 录音结束后，调用后端语音识别接口，传递音频及方言类型参数。
- 显示识别文本，允许用户编辑校对。
- 用户确认后，将文本录入联系内容。

#### 3.3 后端对接

- 确认语音识别接口可用，支持多方言参数。
- 处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同方言、音频质量下的识别效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如录音进度、识别进度提示等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
