# 儿童趣味训练（AI绘画配图）功能计划与ToDoList

## 一、背景与目标

为儿童语音康复训练场景，提供AI智能配图功能。通过AI绘画API为训练语料自动生成趣味性强、贴合内容的图片，提升儿童训练兴趣和参与度。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位儿童训练相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、API调用方式。
3. `src/pages/` 下儿童训练页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展AI绘画API调用。
5. 后端API文档，明确AI绘画API参数与返回值。

## 三、详细实现计划

### 1. 需求分析

- 针对儿童训练语料，自动生成趣味配图，支持多次生成与选择。

### 2. 技术方案

- 前端：配图入口、API调用、图片展示与选择、保存。
- 后端：AI绘画API生成图片，返回图片URL或Base64。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、API调用方式。
- 明确后端API路径、参数、返回值。

#### 3.2 前端开发

- 儿童训练页面新增“AI配图”按钮。
- 用户输入或选择语料后，点击按钮调用AI绘画API。
- 展示生成的图片，支持多次生成与选择最佳配图。
- 支持图片保存、替换、导出等操作。

#### 3.3 后端对接

- 确认AI绘画API可用，支持多语料内容输入。
- 处理鉴权等安全问题。

#### 3.4 测试与优化

- 测试不同语料内容下的配图效果。
- 前后端联调，异常处理与用户提示。
- 优化体验，如进度提示、图片加载优化等。

#### 3.5 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
