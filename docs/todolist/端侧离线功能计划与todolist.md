# 端侧离线功能计划与ToDoList

## 一、背景与目标

为保障医疗健康场景下用户隐私，集成端侧7B大模型SDK，实现本地推理与数据处理，用户数据无需上传云端，降低隐私泄露风险。

## 二、文档与代码调研

1. `docs/02_项目结构.md`：定位端侧相关模块。
2. `docs/03_1_前端概述.md`、`docs/03_2_API通信.md`：了解前端页面结构、SDK集成方式。
3. `src/pages/` 下端侧功能页面代码，确定集成入口。
4. `src/api/` 目录下API相关文件，查找/扩展本地推理API调用。
5. 端侧7B SDK文档，明确集成方式与API。

## 三、详细实现计划

### 1. 需求分析

- 用户数据本地处理，推理、识别等AI能力全部端侧完成。

### 2. 技术方案

- 前端：本地SDK集成、推理入口、数据本地化处理。
- 后端：仅作辅助或无后端依赖。

### 3. 具体步骤

#### 3.1 文档与代码调研

- 阅读上述文档，梳理页面、数据流、SDK集成方式。
- 明确端侧SDK API、模型加载方式。

#### 3.2 前端开发

- 集成本地7B SDK，设计本地推理入口。
- 实现数据本地化处理、推理结果展示。
- 支持模型加载、切换、升级等操作。

#### 3.3 测试与优化

- 测试不同设备下的本地推理效果与性能。
- 优化模型压缩、硬件适配，降低算力与存储需求。
- 异常处理与用户提示。

#### 3.4 文档与上线

- 更新用户手册和开发文档。
- 部署上线，收集反馈优化。
