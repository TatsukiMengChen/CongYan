# 02. 项目结构

本项目遵循 Tauri 应用的标准目录结构，并将前端与后端代码分离在不同的目录中，以保持代码的清晰和可维护性。

## 1. 顶层目录结构

```
cong-yan/
├── docs/                # 存放所有开发文档
├── public/              # 存放静态资源
├── src/                 # 前端源代码 (React + TS)
├── src-tauri/           # 后端源代码 (Rust + Tauri)
├── .github/             # (可选) GitHub 相关配置，如 CI/CD Actions
├── eslint.config.js     # ESLint 配置文件
├── package.json         # Node.js 项目配置文件，管理依赖和脚本
├── pnpm-lock.yaml       # pnpm 锁定文件，确保依赖版本一致性
├── README.md            # 项目简介
├── tsconfig.json        # TypeScript 全局配置文件
├── uno.config.ts        # UnoCSS 配置文件
└── vite.config.ts       # Vite 配置文件
```

## 2. 核心目录详解

### 2.1. `/src` (前端)

此目录包含了所有前端相关的代码，使用 React 和 TypeScript 编写。

```
src/
├── api/         # API 请求模块，用于与后端服务通信
├── assets/      # 前端使用的静态资源（如图片、SVG）
├── components/  # 可复用的公共 React 组件
├── hooks/       # 自定义 React Hooks
├── pages/       # 页面级组件，代表应用的不同视图
├── store/       # 全局状态管理 (Zustand)
├── types/       # 全局 TypeScript 类型定义
├── utils/       # 工具函数库
├── App.tsx      # 应用根组件
├── main.tsx     # 应用入口文件
└── routes.tsx   # 路由配置文件
```

### 2.2. `/src-tauri` (后端)

此目录包含了所有后端相关的代码，使用 Rust 编写，并由 Tauri 驱动。

```
src-tauri/
├── build.rs         # Rust 构建脚本
├── capabilities/    # Tauri 能力权限配置文件
├── icons/           # 应用图标
├── src/             # Rust 源代码
│   └── main.rs      # Rust 应用主入口
├── target/          # Rust 编译产物目录
└── tauri.conf.json  # Tauri 应用核心配置文件
```

### 2.3. `/public`

该目录用于存放不会被 Vite 处理的纯静态资源。在构建时，此目录下的所有文件都会被直接复制到输出目录 `dist` 的根目录。例如，`public/logo.png` 在应用中可以通过 `/logo.png` 访问。

## 3. 关键配置文件

- **`vite.config.ts`**: Vite 的配置文件，用于配置开发服务器、构建选项、插件等。
- **`uno.config.ts`**: UnoCSS 的配置文件，用于定义原子化CSS的规则、预设和快捷方式。
- **`tsconfig.json`**: TypeScript 编译器配置，定义了项目的编译选项、文件包含/排除规则等。
- **`src-tauri/tauri.conf.json`**: Tauri 应用的核心配置文件。在这里可以配置应用名称、标识符、窗口行为、原生API权限、构建选项等。
- **`package.json`**: 定义了项目的前端依赖、开发脚本（如 `dev`, `build`）以及项目元数据。
