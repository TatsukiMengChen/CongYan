# 03_4. UI与样式

本文档旨在介绍聪言项目前端的样式方案和可复用的公共UI组件库。

## 1. 样式方案

项目采用了多种现代化的样式技术，以实现灵活、高效且可维护的UI开发。

### 1.1. 原子化 CSS (UnoCSS)

项目的核心样式方案是 [**UnoCSS**](https://unocss.dev/)。UnoCSS 是一个即时的原子化 CSS 引擎，它集成了多种原子化CSS框架的优点（如 Tailwind CSS），并提供了卓越的性能。

配置文件 `uno.config.ts` 的核心设定如下：

- **预设 (Presets)**:

  - `presetUno()`: 提供了默认的、功能丰富的工具类集。
  - `presetIcons()`: 允许开发者直接在 class 中使用来自 [Iconify](https://iconify.design/) 的海量图标，例如 `<div class="i-mdi-home" />`。

- **快捷方式 (Shortcuts)**: 为了提高开发效率，定义了一些常用的 flex 布局快捷方式：
  - `flex-center`: 实现 `display: flex; align-items: center; justify-content: center;`
  - `flex-between`: 实现 `justify-content: space-between;`
  - `flex-around`: 实现 `justify-content: space-around;`
  - `flex-evenly`: 实现 `justify-content: space-evenly;`

### 1.2. UI 组件库

项目同时集成了两大主流的 React UI 组件库，以满足不同场景下的需求：

- **[Ant Design](https://ant.design/)**: 用于构建高质量、企业级的后台界面和复杂表单。
- **[MUI (Material-UI)](https://mui.com/)**: 提供了遵循 Material Design 设计规范的丰富组件。

在 `src/main.tsx` 中，通过 `ConfigProvider` (Ant Design) 和 `ThemeProvider` (MUI) 为这两个库注入了全局主题，确保了应用整体风格的统一，并实现了暗黑/明亮模式的切换。

### 1.3. 全局样式与动画

- **`src/index.scss`**: 定义了一些全局的基础样式。
- **`src/animate.css`**: 包含了用于页面切换和组件过渡的 CSS 动画类。

## 2. 公共组件 (`src/components/`)

`src/components/` 目录存放着在应用多个页面或模块中可被复用的UI组件。

- **`Navbar.tsx`**: 一个通用的导航栏组件，可用于应用内不同页面的顶部。
- **`OptionButton.tsx`**: 封装好的选项按钮，可能带有特定的点击效果或样式。
- **`ScrollView.tsx`**: 一个可滚动的视图容器，可能封装了自定义滚动条或特定行为。
- **`Switch.tsx`**: 一个封装的开关（Toggle）组件。
- **`TextField.tsx`**: 一个封装的文本输入框，可能集成了校验逻辑或特定样式。
- **`PrivacyPolicy.tsx`**: 用于展示"隐私政策"内容的静态组件。
- **`UserAgreement.tsx`**: 用于展示"用户协议"内容的静态组件。
- **`DebugOverlay.tsx`**: 一个仅在开发模式下显示的调试悬浮层，用于提供开发过程中的辅助信息。
