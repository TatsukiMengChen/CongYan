# 03_1. 前端概述

本文档旨在阐述聪言项目前端的技术选型、核心架构和基本设计思想。

## 1. 核心技术栈

前端的核心是基于 **React (v18)** 和 **Vite** 构建的现代化单页面应用 (SPA)。

- **UI框架**: [React](https://react.dev/)
- **开发与构建工具**: [Vite](https://vitejs.dev/)
- **编程语言**: [TypeScript](https://www.typescriptlang.org/)
- **路由管理**: [React Router](https://reactrouter.com/) (v6)
- **样式方案**: [UnoCSS](https://unocss.dev/) (原子化CSS) + [Sass](https://sass-lang.com/)
- **UI组件库**: [Ant Design](https://ant.design/) & [MUI](https://mui.com/)
- **状态管理**: [Zustand](https://github.com/pmndrs/zustand)

## 2. 应用启动流程

应用的生命周期始于 `src/main.tsx` 文件。

1.  **渲染入口**: `ReactDOM.createRoot` 在 `index.html` 的 `<div id="root"></div>` 上挂载 React 应用。
2.  **主题注入**: 在根组件 `<Root>` 中，为 `MUI` 和 `Ant Design` 注入了全局主题 (`ThemeProvider` 和 `ConfigProvider`)。同时，它会监听操作系统的色彩模式（暗黑/明亮模式）并动态切换应用主题。
3.  **路由渲染**: 最终，入口文件会渲染 `<AppRouter />` 组件，该组件是整个应用路由系统的起点。

## 3. 路由设计

应用的路由系统在 `src/routes.tsx` 中定义，具有以下特点：

### 3.1. 路由结构

- **布局路由 (Layout Route)**: `App.tsx` 组件作为主要的布局容器，它包含了一个全局的底部导航栏。所有主页面（如首页、咨询、我的）都通过 `<Outlet />` 渲染在 `App.tsx` 内部，从而共享相同的导航布局。

- **页面路由**:
  - **主页面**: `/home`, `/contact`, `/profile`。
  - **功能页面**: `/train`, `/tasks`, `/analysis`, `/patients`, `/settings` 等，每个核心功能都有其独立的路由。
  - **认证页面**: `/login`, `/register`，用于用户登录和注册。

### 3.2. 路由守卫 (Protected Routes)

为了保护需要用户登录才能访问的页面，项目实现了一个 `<ProtectedRoute />` 组件。该组件会检查 [Zustand](./03_3_状态管理.md) store 中的用户认证状态 (`isAuthenticated`)。如果用户未登录，任何访问受保护路由的尝试都将被重定向到 `/login` 页面。

```tsx
// src/routes.tsx
const ProtectedRoute = ({ children }) => {
  const { isAuthenticated } = useAuthStore();
  return isAuthenticated ? <>{children}</> : <Navigate to="/login" replace />;
};

// 用法
<Route
  path="/train"
  element={
    <ProtectedRoute>
      <TrainTextListPage />
    </ProtectedRoute>
  }
/>;
```

### 3.3. 页面切换动画

应用在路由切换时提供了流畅的过渡动画。通过 `react-transition-group` 库，并结合监听 `useNavigationType`（判断是前进还是后退），为页面的推入（PUSH）和弹出（POP）应用了不同的 CSS 动画，提升了用户体验。

## 4. 全局布局

`src/App.tsx` 定义了应用的全局布局。

- **底部导航**: `App.tsx` 中实现了一个 `<mdui-navigation-bar>`，作为应用的核心导航。
- **动态显隐**: 该导航栏能感知全局输入状态（通过Zustand Store），当用户激活输入框（如聊天输入）时，导航栏会自动隐藏，为内容区提供更多空间。
- **内容区**: 通过 `<Outlet />` 承载当前路由匹配到的页面组件。
